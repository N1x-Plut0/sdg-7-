# Light the Valley (SDG 7 game, draft)

A small browser game about **SDG 7: Affordable and clean energy**. You run the energy plan for a valley
from 2021 to 2030. Families move in every year and need electricity. Build solar, wind, small hydro or
coal, upgrade homes to be energy efficient, and try to power every home without filling the air with smog.

The look follows the class presentation: cream paper, colored-pencil drawings, handwritten text.

## Play

Open `index.html` in a browser. No install needed.

## Rules (v0.1)

- Each year: build things, then press **End year**.
- Each home needs 2 MW (1 MW once it's an *efficient home*).
- Solar: $20k, about 3 MW, follows the sun. Wind: $35k, about 5 MW, follows the wind.
  Small hydro: $60k, steady 9 MW, must be next to the river. Coal: $15k, steady 8 MW, but $3k/year to run and +7 pollution/year.
- You earn $15k + $6k per powered home every year.
- Air pollution at 100 ends the game.
- In 2030 you get up to 3 stars: 100% of homes powered, 80%+ clean power, pollution under 30.
